# 课设智辅 v2.3 · 液态玻璃课程设计工作台

面向工科计算类课程设计的本机工作台。当前模块是**等截面线弹性简支梁：满跨均布荷载 + 单个集中荷载**，支持矩形、实心圆和自定义 I/W 截面。

原线上入口：[GitHub Pages](https://zjmnb66611.github.io/course-design-assistant/)。本地修改不代表线上已更新，请根据实际提交与部署版本确认。

## 使用

在浏览器中打开 index.html，并保留同级 assets 文件夹。无需安装依赖、启动服务或登录。

可以直接输入“梁长六米”或“我想做梁的课设”，点击“帮我整理，继续”。系统先保留已知条件，每次追问一项；不知道的可先跳过，稍后到参数页补齐。正式任务书、完整示例和手动参数入口仍可使用。

使用 Node.js 生成单文件离线版，不需要 npm 依赖：

    node tools/build-offline.cjs

输出 dist/课设智辅-v2-离线版.html，可单独复制并直接打开。脚本会为内联应用脚本生成精确的 CSP SHA-256 白名单。

| 工作环节 | 能力 |

| 自由描述 | 支持常见口语、中文数字、简写和部分条件；逐句补充，可跳过未知项；仍支持 TXT / Markdown 和来源核对 |
| 参数 | 手工填写、教学材料预设、有限数值、尺寸、位置、限值与单位检查 |

| 报告 | 过程与数据表，指定格式的关键数值一致性检查，未识别内容不作通过判断 |

## 数据与安全

- 无第三方框架、CDN、远程字体或分析 SDK。首次加载仍会访问托管站点资源；显式点击外部参考链接时会访问对应网站。
- 任务、参数、报告默认只留在页面内存。主题、配色和动态效果开关偏好保存到本机浏览器。
- 鼠标位置仅在内存中用于装饰绘制，不写入项目、草稿或本机存储，也不发送请求。使用最多 480 × 280 的局部画布，DPR 为 1，最多 32 个粒子，约 0.42–0.6 秒淡出。空闲、滚动、窗口失焦、页面隐藏及任务处理时停止光迹绘制。触屏不启用鼠标光迹，系统减少动态或高对比度模式停用动效。
- 去掉持续流动背景和装饰环动画，保留玻璃样式与交互反馈；数字提前绘制成字形图集，鼠标事件不再反复测量按钮或改写高光样式。图表与采样表进入图表页后才创建。
- 此为使用网页 CSS / Canvas 实现的 Apple Liquid Glass 风格表达，不是调用 Apple 原生材质接口。不支持背景模糊的浏览器使用实色控件。
- 主动开启本机草稿才保存任务、参数、待检查报告和方案输入。刷新后需手动恢复；清除草稿同时停用保存。
- 草稿与下载文件没有加密；共享设备请清除草稿。草稿写入等待或失败时保留离开页面提醒。
- 文本导入上限 1 MB / 20 万字符；项目上限 1.5 MB，检查版本、类型、字段、长度、数量和有限数字。输入不作为脚本或指令执行。自然语言由本机规则解析，不是通用大模型；不能保证理解所有表达，无法确认的内容会保留原文并等待核对。
- 参数变化后旧结果、图表、报告、检查与人工自查失效；数值核验未通过时阻止正常报告导出。
- CSP 禁止后台连接、任意脚本、对象、表单和 Worker。内联样式权限仅用于布局和数值 SVG，脚本无此例外。
- vercel.json 提供可选托管响应头，实际生效须部署后验证；GitHub Pages 不读取这些配置。

详见 [SECURITY.md](SECURITY.md)。

## 计算范围

采用 Euler–Bernoulli 线弹性梁模型与叠加法。标准算例包括均布荷载 qL²/8 和 5qL⁴/(384EI)、跨中集中荷载 PL/4 和 PL³/(48EI)、偏心集中荷载、混合荷载、支座荷载与零荷载。

基础公式背景参考：[University of Alberta / Canadian Wood Council 梁弯曲讲义](https://cwc.ca/wp-content/uploads/2025/08/CWC-Lecture-4-Design-of-bending-members1.pdf)。不据此引用材料设计值或声称完成中国现行规范验算。材料预设为教学建议值，以课程任务书、教材和适用规范为准。

不覆盖非简支边界、多个集中力、局部或非均匀荷载、剪切变形、稳定、疲劳、节点与规范全套条文。L/10 只是极端变形报警阈值，不能证明小挠度模型适用。工具用于课程教学验算。

## 目录

- tests/engine.test.cjs：无依赖回归测试。
- tools/build-offline.cjs：单文件构建。
- vercel.json：可选 Vercel 响应头配置，参考 [官方项目配置](https://vercel.com/docs/project-configuration/vercel-json)。
