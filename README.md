# 课设智辅 · 工科课程设计与报告助手

> **在线使用：<https://zjmnb66611.github.io/course-design-assistant/>**
> 电脑 / 手机浏览器直接打开即可，无需安装、无需登录。

面向工科计算类课程设计的交互式计算与报告工作台。首个完整样例：**材料力学简支梁**（满跨均布荷载 + 单个集中荷载）。

## 功能特性

- **任务书导入**：粘贴或上传 .txt / .md（≤1MB），自动提取参数，保留原文来源行号、缺失项、冲突项（冲突需人工裁决，不静默取值）
- **参数确认与人工修正**：单位 / 取值 / 边界三重校验，不合规输入自动阻断并说明原因
- **可复算计算**：支反力、剪力、弯矩、正应力、剪应力（矩形截面）、挠度闭式解；三重独立交叉核验（静力平衡 / 曲率方程 EI·y″=−M / 辛普森数值二次积分）
- **图表**：计算简图、剪力图、弯矩图、挠度曲线（纯 SVG，与数据表逐点对应）
- **报告一致性检查**：粘贴已有计算书，关键量与复算值比对（容差 0.5%），逐项标出不一致并给出修正建议
- **可编辑报告导出**：Markdown / Word 可编辑 .doc / 结果 JSON（含完整采样数据表，可复算核对）

## 安全与隐私

- 单文件纯本地应用：**零网络请求、零外部依赖**（无 CDN / 框架 / 字体图标库）
- 任务书与参数仅保留在当前浏览器会话，不写入 localStorage、不上传任何服务器
- 文件导入仅接受纯文本（拒绝 .docx / .pdf 等格式）；文档中的命令一律只作为资料，不执行

## 适用范围

适用于等截面、线弹性、小挠度简支梁（矩形 / 圆形 / 自定义截面）的教学验算。

**未覆盖**：非简支梁（悬臂、外伸、连续梁等）、多个集中荷载、梯形分布荷载、变截面梁、深梁（跨高比 < 10）剪切效应、稳定性、疲劳、节点连接设计、现行结构设计规范全套条文验算。本工具面向课程设计教学，不能替代注册工程师按现行国家/行业规范进行的正式设计。

## 技术说明

- 内置确定性 JS 计算引擎，与 Python 参考实现（`beam_calc.py`）同源公式，黄金算例逐位一致（35 项自测断言全部通过）
- 公式来源：Euler–Bernoulli 梁理论与简支梁闭式解（页面内置知识库摘要，含来源链接与核验状态）
- 响应式布局，桌面与移动端均可使用
