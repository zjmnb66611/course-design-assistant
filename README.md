# 活动智策 · 学院活动策划与预算助手

版本 3.0.0。原课设网站的业务改为学院活动策划，沿用原液态玻璃界面、六步导航、主题、配色与动效。原课设版本在 Git 历史和本轮独立源码备份中保留，旧草稿键不会被活动项目覆盖。

## 使用

直接打开 index.html；独立策划助手打开 agent.html。无需安装运行依赖、登录或项目服务。实际部署前，本机文件不代表原 GitHub Pages 已更新。

1. 写一句活动想法，或导入 TXT/Markdown。
2. 核对名称、人数、预算、日期、时刻、目标和地点，保留来源提示。
3. 查看分阶段策划流程和待确认事项。
4. 添加或编辑预算明细，区分询价与占位、已确认与待确认资金、计划与实际支出。
5. 修改执行任务、负责人、相对日期和状态，记录人工核对。
6. 导出报告、预算 CSV、执行日历或项目备份。

“使用说明”包含真实浏览器录制的中文字幕操作演示和文字步骤。视频无音轨，点击才加载；原梁课设视频没有作为活动演示沿用。

## 主要能力

- 活动需求提取：中文数字、常见口语、明确年月日、来源行号。多个预算/人数或无效日期提示裁定，不把模糊日期猜成确定时间。
- 学术讲座、文体、志愿、培训交流、迎新团建五类策划；流程分钟数与活动时长一致，户外与较大规模事项另列提示。
- 整数分预算：数量最多3位小数、单价最多2位小数，逐项四舍五入，预备金另列；计划超支和已登记实际支出超上限分别提示。
- 资金管理：待确认赞助和拟申请经费不计入已确认资金；确认状态是用户记录，不是系统验证到账。
- 核销与复盘：空实际金额表示未核销，显式0元表示已登记；未全部核销时不作完整实支偏差判断。
- 最多4个方案输入快照，保留各自原文，载入重新核算；预算、条件变化使相关人工核对记录失效。
- 执行清单、相对活动日的任务日期、状态推进、全天日历 ICS、Markdown、Word兼容HTML .doc、CSV、项目 JSON 与可选本机草稿。
- 预算、任务、资金编辑和项目变更可撤销上一次修改；后续修改或刷新不保留多步撤销历史。

## 独立助手与 TeleAgent

agent.html 是可独立打开的本地规则工作流，不含大模型。它会追问名称/人数/预算，实际调用需求解析、流程规划、预算建议、整数分核算、检查和知识查询工具，展示调用记录。建议只有在用户点击“应用”后写入项目。

assets/activity-agent-package.zip 是可移植接入资料包，包含 SKILL.md、知识库、工具契约/JSON Schema、示例、相同核心引擎的 Node CLI 和可选 MCP stdio 适配器。包内核心哈希与网页一致，解压后的 CLI 已实际运行；MCP 消息处理函数经过单元测试，没有启动常驻进程或端口服务。TeleAgent 平台账号中的导入、权限、模型调用和会话运行尚未验证，不称为已发布智能体。

TeleAgent 官方产品说明支持技能导入与 MCP 扩展：https://www.teleai.com.cn/product/teleagent 。本包的契约和配置示例属于本项目，不是冒充官方配置格式。目标客户端需按其实际配置界面绑定本机工具。

## 边界

预算建议是按上限比例分配的占位金额，不是实时市场价格。知识库是通用组织与核算规则，不是本校制度；审批、现场安排与资金依据需要用户核对。工具不自动采购、付款、联系、报名或提交审批。

数据在本机处理。草稿默认关闭，换设备用项目备份。网页不提供账户、多用户同步或关闭网页后的推送。旧版工程计算 JS 和算例测试保留作历史兼容资料，但新页面不加载它们；活动项目不能导入旧课设格式。

## 构建与检查

```powershell
python tools/build-agent-package.py
node --test tests/activity.test.cjs tests/activity-mcp.test.cjs
python tools/check-agent-package.py
node tools/build-offline.cjs 活动智策-离线版.html
node tools/build-offline.cjs 活动智策-独立助手-离线版.html agent.html
```

单文件包含样式、脚本、视频和接入包，生成精确脚本 CSP 哈希；不需要 Tailwind/CDN 或外部字体。旧样式和动效文件保持原样，只为新业务明细、编辑窗和助手对话补充 activity.css。

浏览器测试：安装 Playwright 后 `node tests/activity-browser.cjs`，直接打开本机文件。可用 NOTICE_PLAYWRIGHT 指定模块路径、NOTICE_BROWSER 指定浏览器、NOTICE_TEST_OUTPUT 指定报告目录；NOTICE_TEST_URL、NOTICE_AGENT_URL 可切换到离线或正式入口。测试只用隔离浏览器和合成活动数据，不启动服务。

新业务测试与原梁引擎测试分开报告；本机测试不代表线上部署、外部 Word/WPS 或日历应用完整兼容，也不代表全量渗透测试。

## 目录

- index.html / agent.html：工作台与独立助手入口。
- assets/activity-core.js：纯数据、规则、核算与导出内容，两端共用。
- assets/activity-app.js：六步活动业务、预算编辑、方案和助手。
- assets/activity-workspace.js：项目、外观、草稿、文件下载和事件。
- assets/activity.css：新业务内容的局部样式。
- agent-package/college-activity-planner：可编辑技能与工具资料。
- tools/：接入包、离线版与包一致性检查。

发布继续使用原 course-design-assistant 仓库和 GitHub Pages 地址。按用户约定，确认暂存区中文提交后再推送；原通知工作台的待发布修改位于另一个仓库，本次不混入。
